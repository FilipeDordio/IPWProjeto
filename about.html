Sobre Este Projeto

Este website foi desenvolvido como parte do projeto da disciplina de Introdução à Programação para a Web (IPW) do Instituto Politécnico de Setúbal, no ano letivo 2025/2026.

O objetivo deste projeto é criar uma plataforma educativa interativa que permita aos utilizadores explorar e compreender a Tabela Periódica dos Elementos de forma visual e organizada.
